# Teleput Web Extension

A button and a context menu to send any link or image to the Teleput bot,
which in turn sends it to you.

It also adds a "Fill contact form" context menu item that fills a page's
contact form with the name, email, subject and message set on the options
page. `<domain>` and `<domain_no_ext>` in the subject or message are replaced
with the site's domain (`example.com.au`) and name (`example`).
